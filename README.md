# robotics-sim
MuJoCo robotics simulation experiments on a Jetson Orin Nano (headless rendering plus interactive viewer).

- `step3_panda.py`: load and render a Franka Panda arm
- `spot_info.py`: inspect the Boston Dynamics Spot model (joints, actuators, keyframes)
- `spot_march.py`: open-loop trot gait, marching in place

Models come from [MuJoCo Menagerie](https://github.com/google-deepmind/mujoco_menagerie) (clone it into this folder).
